V1 · 일관성 붕괴로 폐기

유튜브 캡처 20장, 3개 이하 각도 → 생성마다 헤드램프와 차체 형태 변동

V2 · 데이터 재구성

공식 보도자료 30장, 각도 중복 없이 선별. 다른 차량이 절반 이상인 사진 제외

VLM 자동 캡션은 API 한도로 중단되어 나머지는 직접 작성, 30장 전부 검수. 바뀌면 안 되는 도장·램프·로고는 트리거 단어에 연결, 캡션에는 각도·배경·조명만 기재

Z-Image Turbo 채택. 같은 데이터와 생성 조건(Step 10, CFG 1, LoRA 강도 1.10)에서 베이스 모델만 교체해 비교. 두 줄 램프는 둘 다 유지, Flux.2 Klein 4B는 원본 디테일, Z-Image Turbo는 배경·질감 프롬프트 반영이 우수. 수치 평가가 아닌 다섯 기준의 육안 비교
