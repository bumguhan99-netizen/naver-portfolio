# SSAFY AI 챌린지 1차 · 재활용품 사진 질문에 답하는 VQA 모델 개선

- **형태:** 개인 참가
- **과제:** 재활용품 사진과 질문을 보고 개수·재질·색상·종류를 묻는 4지선다에 답하기
- **결과:** Public 20위에서 최종 7위로 상승 (대회 최종 공지 기준). Public 0.93338에서 최종 0.945
- **환경:** 로컬 16GB GPU, 학습 → 추론 → 제출 한 바퀴 약 50분, 하루 제출 20회

> 대회 데이터와 제출 파일은 포함하지 않았습니다.

## 요약

점수를 올리기 전에 학습·추론 코드의 버그부터 고쳤고, 리더보드가 아니라 로컬 검증 정확도로 판단했습니다.

## 데이터

| 구분 | 내용 |
|---|---|
| train | 5,073문항 |
| test | 5,074문항 |
| dev | 정답 없이 여러 명의 응답만 있음 |

## 진행 순서

| # | 문제를 본 지점 | 바꾼 것 | 결과 |
|---|---|---|---|
| 1 | 기준 코드에 라벨 마스킹이 없어 프롬프트·이미지 토큰 전체에 loss가 걸림 | 정답 토큰에만 loss를 걸도록 수정, GradScaler와 bf16 혼용 정리 | 학습 신호 정상화 |
| 2 | 2토큰 생성 후 파싱하고, 실패하면 무조건 "a"를 제출 | a/b/c/d 첫 토큰 logits를 직접 비교 | 파싱 실패 0, 추론 속도 향상 |
| 3 | 글자·작은 물체를 놓치는 오답 | 최대 해상도 576·28² → 1,024·28², 보기 순서 회전 TTA, 정답 분포 보정 | 검증 0.7233 → 0.7600 (+3.7%p) |
| 4 | 3B 모델의 한계 | Qwen3-VL-8B LoRA (r=16, α=32, 비전 블록 포함, 학습 파라미터 0.60%), 보기 순서를 섞어 학습 | Public 0.93338 |
| 5 | 라벨 있는 데이터 부족 | dev 응답 중 3·4표 합의 3,508건을 pseudo-label로 추가해 7,566건으로 확장 | 최종 0.945 |

모델은 Qwen2.5-VL-3B QLoRA에서 Qwen3-VL-8B LoRA로 교체했습니다.

## 로그를 보고 확인한 것

pseudo-label을 넣은 뒤 학습셋의 "개수" 문항 비중이 51.2%로, 검증셋(31.9%)보다 크게 높아진 것을 학습 로그에서 찾았습니다. 데이터를 늘리면 분포도 같이 바뀐다는 점을 이때 처음 숫자로 확인했고, 2차에서는 외부 데이터 비율을 통제하는 실험으로 이어졌습니다. 2차의 15%·30% 혼합 실험과 외부 데이터 5% 파일럿이 그 연장입니다. ([2차 문서](01_ssafy-ai-challenge-2.md) 참고)

## 1차에서 정리한 원칙

- 학습 전에 사전학습 모델의 zero-shot 점수부터 잰다
- loss가 아니라 로컬 검증 정확도로 판단한다. 리더보드로 튜닝하지 않는다
- 사전학습 모델, 외부 데이터, API 허용 여부를 먼저 확인한다
- 라벨 마스킹과 파싱 같은 형식 버그가 모델보다 먼저 점수를 깎는다

## 해석의 한계

대회 후 점수가 제출 당시 Public보다 오른 것은 Public에만 맞추지 않은 결과로 봤습니다. 다만 이것이 다른 참가자의 과적합이나 이번 일반화의 증거는 아닙니다. 7위는 대회 최종 공지 기준입니다.
